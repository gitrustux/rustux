rboot - the boot manager

    rboot starts at power-on (from \EFI\BOOT\BOOTX64.EFI on the stick, or
    from a firmware entry for \EFI\Rustica\rboot.efi) and shows what can
    be started:

      Try (desktop or server) / Install Rustica  on the installation stick
      Rustica                       the system
      Rustica (recovery)            a root shell, no login (rescue)
      Rustica (live, in memory)     the system from memory, disks untouched
      Windows Boot Manager          found on the disks
      Linux (...)                   shim, GRUB or systemd-boot found
      Firmware setup                restarts into the firmware's setup

    Up/Down choose, Enter starts, e edits the command line once (Enter
    starts, Esc cancels), d makes the choice the default. Any key stops
    the countdown.

    Its settings are on the EFI partition: \loader\loader.conf (default,
    timeout, editor, auto-entries, auto-firmware) and one file per entry
    in \loader\entries (title, efi, options, bootfs, sort-key), as
    systemd-boot's. Kernel command line words: root=, rescue, quiet,
    autologin=, noefi, bootfs=, panic=N (restart N s after a kernel
    panic) (man rustux, docs/FS.md).

    Boot counting: an entry file ID+LEFT.conf has LEFT tries. rboot counts
    each one before starting it (ID+LEFT-1-1.conf); the system makes it
    ID.conf once it is up (bootctl bless). At +0 the entry failed to
    start: it and the other entries of its image go to the end of the
    menu, "(failed to start)", and the next one starts by default (the
    previous system image). rpg writes new images' entries this way (man
    rpg, THE SYSTEM).
