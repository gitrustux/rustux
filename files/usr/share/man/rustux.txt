rustux - the system: what runs, where things are

PROCESSES
    The kernel starts init, which runs the console, the keyboard driver,
    the file system service (fsd), the device manager, authd (su, sudo,
    passwd) and login, which starts your shell. Programs run in jobs, as
    the user who started them; ps lists them, kill ends one, top shows
    what is busy.

THE FILE TREE
    /           in memory (tmpfs), writable
    /tmp        scratch files
    /root       root's home directory; /home/NAME for other users
    /etc        settings: hostname, timezone, keymap, passwd, group,
                shadow, sudoers, mtab (copied from the boot image at start;
                on a disk root the first time only)
    /var/log    auth.log (su, sudo)
    /bin        programs (read-only, from the boot image)
    /usr        read-only data: share/man (manual pages), share/keymaps,
                share/zoneinfo, share/tests (the command tests)
    /boot       the boot image itself
    /dev        null and zero

TIME AND LANGUAGE
    /etc/timezone names the time zone (America/Chicago, Europe/Berlin, ...).
    Text is UTF-8. timedatectl and localectl change the zone and the
    keyboard layout.

USERS
    root and the users made with useradd; files have owners and modes
    that are enforced. man users.
