network.conf - the network interfaces at boot

FILE
    /etc/network.conf

    Read by the network service (netd) when it starts and each time a
    network card appears. One line per interface; # starts a comment.

    NAME dhcp
        an address, the default route and DNS servers from a DHCP
        server, renewed as the lease runs; the host name (/etc/hostname)
        goes with the requests
    NAME static ADDRESS/PREFIX [GATEWAY]
        a fixed address, and the default route through GATEWAY
    NAME off
        left alone
    NAME static6 ADDRESS/PREFIX [GATEWAY]
        an IPv6 address (and default route) besides what routers
        advertise; the card still gets IPv4 by DHCP unless it has a line
        for that too
    dns ADDRESS...
        DNS servers, before DHCP's (netd writes /etc/resolv.conf)
    search DOMAIN...
        domains tried after short names

    NAME is eth0, eth1, ... (ip link), the cards in PCI order. A card
    without a line gets DHCP. The image's file says "eth0 dhcp".

    After changing it: sudo svc restart netd (ip changes the running
    state without the file).
